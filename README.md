# 🎲 Juego del Número Secreto

Un mini‑juego web para poner a prueba tu intuición: adivina el número secreto en el menor número de intentos.  

---

## ✨ Lo que ofrece
- 🎯 Pistas en tiempo real (mayor/menor)  
- 🔢 Contador de intentos  
- 🔄 Reinicio rápido  
- 📱 Diseño responsive  

---

## 🛠️ Tech Stack
- **HTML5** → estructura  
- **CSS3** → estilo y animaciones  
- **JavaScript** → lógica del juego  

---

## 🚀 Cómo jugar
1. Abre `index.html` en tu navegador.  
2. Ingresa un número y pulsa **Intentar**.  
3. Sigue las pistas hasta acertar.  
4. ¡Celebra tu victoria y revisa tus intentos! 🎉  

---
